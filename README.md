# МАКЕТ // БЮРО

Одностраничный промо-сайт макетной мастерской: архитектурное и промышленное макетирование. Лендинг в «чертёжно-бюро» стилистике с интерактивной 3D-сценой в hero-секции, портфолио с фильтрами и модальными окнами проектов, разделами о технологиях и этапах работы, а также формой заявки на расчёт стоимости.

## Структура проекта

```
maketka/
├── index.html     # Единственная страница: hero, секции, модальное окно, футер
├── style.css      # Все стили (адаптивная вёрстка, тёмная тема, анимации)
├── app.js         # UI-логика: навигация, скролл, фильтры, модалка, форма
├── scene.js       # 3D-сцена на Three.js (сборка архитектурного макета в hero)
└── projects.js    # Данные портфолио (window.PROJECTS) + генератор SVG-визуалов
```

## Технологии

- **Чистый HTML5 / CSS3 / JavaScript** — без сборки и фреймворков
- **Three.js v0.164.1** — WebGL-сцена, подключается как ES-модуль через importmap с CDN (`unpkg.com`)
- **Lenis v1.1.13** — плавный скролл (CDN)
- **Google Fonts** — Cormorant Garamond, Manrope, JetBrains Mono

> ⚠️ Для работы Three.js (модуль `scene.js`) страница должна открываться по HTTP(S) или локально через сервер — при открытии `index.html` напрямую по `file://` ES-модули могут быть заблокированы браузером.

## Функциональность

- **Hero-сцена**: анимированная покадровая «сборка» макетного здания (WGS-стиль, допуск ±0.05 мм), реакция на скролл, затемнение и параллакс
- **Плавный скролл** по якорным ссылкам (Lenis) с учётом `prefers-reduced-motion`
- **Портфолио**: карточки проектов рендерятся из `projects.js`, фильтры (жилые / градостроительство / промышленные), модальное окно с характеристиками (масштаб, габариты, материалы, срок)
- **Секции**: философия и метрики (анимированные счётчики), технологии/материалы, этапы производства
- **Форма заявки**: клиентская валидация (имя + телефон/Telegram), экран успешной отправки (демо — без реальной отправки на сервер)
- **Адаптивность**: мобильное бургер-меню, скрытие навигации при скролле

## Запуск

Сборка не требуется. Достаточно любого статического сервера, например:

```bash
# Python
python -m http.server 8080

# или Node
npx serve .
```

Затем открыть `http://localhost:8080` в браузере.

## Заметки для разработки

- Добавление проектов: расширить массив `window.PROJECTS` в `projects.js` (поля: `id`, `category`, `categoryLabel`, `title`, `scale`, `size`, `materials`, `time`, `description`, `svgType`). Нужные значения `category`: `residential`, `urban`, `industrial`
- Визуалы карточек — генерируемые SVG (`window.projectSVG(svgType)` в `projects.js`), фотографии не используются
- Контактные данные и адрес захардкожены в `index.html` (секция `contact`)
- Форма не отправляет данные на бэкенд — при подключении реальной отправки нужно доработать обработчик `submit` в `app.js`
